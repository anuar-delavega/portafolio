AI job-search pipeline

Customized Career-Ops setup — agents that evaluate offers, tailor the CV and track applications.

🔒 Private code — demo available on request
Role
Setup, customization and operation
Period
Apr 2026
Stack
  • Claude Code
  • Node.js
  • Playwright
  • Markdown
Highlights
  • Offer evaluation against my own profile and criteria.
  • Tailored CVs per posting, generated from a single source (cv.md).
  • Application tracker with deduplication and posting liveness checks.
  • Pairs with Scrapped LinkedIn to feed the pipeline with fresh postings.

Why

Companies use AI to filter candidates; this pipeline uses AI so the candidate can filter companies. I adopted and customized it for my search for Delivery and Program Management roles.

Built on the open-source Career-Ops project by santifer (MIT license). My work was setting it up, customizing it and running it.
