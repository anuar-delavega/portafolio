Pipeline de búsqueda de empleo con IA

Implementación personalizada de Career-Ops — agentes que evalúan ofertas, adaptan el CV y dan seguimiento a postulaciones.

🔒 Código privado — demo disponible bajo solicitud
Rol
Configuración, adaptación y operación
Periodo
Abr 2026
Stack
  • Claude Code
  • Node.js
  • Playwright
  • Markdown
Lo más relevante
  • Evaluación de ofertas contra el perfil y los criterios propios.
  • Generación de CVs adaptados a cada vacante a partir de una sola fuente (cv.md).
  • Tracker de postulaciones con deduplicación y verificación de vigencia de las vacantes.
  • Se combina con Scrapped LinkedIn para alimentar el pipeline con vacantes nuevas.

Por qué

Las empresas usan IA para filtrar candidatos; este pipeline usa IA para que el candidato filtre empresas. Lo adopté y lo personalicé para mi búsqueda de roles de Delivery y Program Management.

Basado en el proyecto open source Career-Ops de santifer (licencia MIT). Mi trabajo consistió en configurarlo, personalizarlo y operarlo.
